# ESG GreenRadar

Mobile-first React prototype for ESG Deathwatch, a hackathon app that turns ESG evidence into a simple Green / Watch / Red risk signal.

## Run locally

```bash
npm install
npm run dev
```

## Project shape

- `src/data` contains the demo company dataset, Discovery cards, and Daily Brief data.
- `src/engine` contains the shared signal, ranking, and alert logic.
- `src/screens` contains the main user journeys for Discovery, Company Detail, Watchlist, Daily Brief, and Search.
- `docs/hackathon` contains the source brief and rubric materials.
