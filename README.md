# GreenRadar

Mobile-first React prototype for GreenRadar, a hackathon app that checks whether a company's sustainability claim is backed by real evidence or at risk of greenwashing.

## Run locally

```bash
npm install
npm run dev
```

## Project shape

- `src/data` contains the demo company claim dataset, Discovery cards, and Daily Brief data.
- `src/engine` contains the shared verdict, ranking, and alert logic.
- `src/screens` contains the main user journeys for Discovery, Company Detail, Watchlist, Daily Brief, and Search.
- `docs/hackathon` contains the source brief and rubric materials.
